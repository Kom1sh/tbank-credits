# Кредиты Т-Банка: когда занимать выгодно

Доклад на 3 минуты для занятия по банковским инструментам. Тема из общего документа группы:
«Т-банк · Кредиты — Протасов». Шесть слайдов: кластер про досрочное погашение разведён на два, поэтому на один слайд больше лимита из задания (1–5). Если нужно строго пять, схлопывается обратно в один слайд.

Живая версия: https://kom1sh.github.io/tbank-credits/ — закрыта от индексации.
PDF рядом: `tbank-credits.pdf`. Текст выступления: `SPEECH.md`.

Пятый слайд закрывает второе задание курса: три отзыва о микрофинансовых организациях
с findozor, 1mbank и topbanki.

## Данные

Ставки и лимиты — страницы tbank.ru, сняты 21 сентября 2026. Ключевая ставка и инфляция —
Банк России, сентябрь 2026. Рост цен на жильё за 2025 год — Домклик и Сбериндекс.
Ограничение переплаты по микрозаймам — Банк России, правила с 1 апреля 2026.

## Как править

```
python3 src/make_slides.py && python3 src/build.py && python3 src/qa.py
```

`src/make_slides.py` — содержание, `src/deck.tpl.html` — оформление, `DESIGN.md` — палитра
и правила. `src/qa.py` обязателен перед показом: ловит вылезший текст, переполненную таблицу
и наложения. Управление в показе: стрелки, `O` — обзор слайдов, `F` — полный экран.
